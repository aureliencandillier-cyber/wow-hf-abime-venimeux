Checklist — Glory of the Venomous Raider

Les 8 hauts faits de L’Abîme Venimeux, un par boss. Tous demandent Normal ou supérieur.

À savoir : les cases sont enregistrées localement dans le navigateur. Chaque membre peut donc suivre sa progression, mais ce fichier n’est pas synchronisé entre plusieurs personnes.
Boss 1 — Nek’zali

Well, Well, Little Sky

Ramener Kupamanduka dans le Soulcoil Well puis tuer Nek’zali
›
Objectif : envoyer la grenouille Kupamanduka dans le puits central.
Baume → Grenouille → Plateforme → Pull → Coup de pied → PUITS → Kill
Sources : Wowhead — HFForgotten Attendant
Boss 2 — Sentinelles ensevelies

Is Venom Stasis A Joke To You?

Chaque Sentinelle doit récupérer >50 % de ses PV max via Vitriolic Stasis
›
A basse → STASE → heal >50 % → B basse → STASE → heal >50 % → Kill
Prenez une marge : le HF demande plus de 50 %, pas exactement 50 %.
Source : Wowhead — HF + retours live
Boss 3 — Explorateurs perdus

Accidental Inclusion

Inclure Hoji dans le combat
›
Fish Basket → Hoji dans l’arène → PAS d’extra-action → Pull → Kill
Sources : Warcraft WikiMMO-Champion — méthode live
Boss 4 — Vashnik

Kept You Waiting Huh?

Faire apparaître puis tuer le Solidified Snake Venom
›
Il faut réunir exactement un add violet + orange + petit rouge.
VIOLET + ORANGE + PETIT ROUGE → superposition → SOLIDIFIED SNAKE VENOM → Kill add → Kill boss
Très pratique : Grip DK + Banish Démoniste. Piège chasseur / Paralysie moine peuvent aider.
Sources : WowheadMMO-Champion
Boss 5 — Sszorak

Jumping Through Hoops

Traverser chaque anneau qui apparaît
›
ENCENS → Pull → Crosswinds → 3 joueurs / 3 anneaux → Kill
Évitez les collisions / Turbulent Gusts pendant le saut.
Source : Wowhead — HF + retours live
Boss 6 — Crochets jumeaux

Taking a Bite out of Slime

Nourrir Ithraz avec 4 slimes dans l’ordre exact
›
1 Crunchy → 2 Sumptuous → 3 Tasty → 4 Jiggly → Kill
Les buffs des slimes durent ~60 min et persistent à travers la mort. Les 4 peuvent être répartis sur plusieurs Ravenous Feasts.
Sources : Wowhead — HF + positionsCrunchy Appetizer
Boss 7 — Autel lové

Watch Out Behind You

Tous les joueurs doivent avoir Unnerving Fixation
›
Dreadmarch → fantômes → LES GARDER → 1 fixation / joueur → tracker OK → Kill
Des retours live signalent une limite de fantômes au-delà d’environ 20 joueurs. Évitez un raid très gros pour ce HF.
Source : Wowhead — HF + retours live
Boss 8 — Ula’tek

No Egg Scramble

Tuer Ula’tek avec le Greasy Hatchling intact
›
A 35 s → B 35 s → C → D → A quand Butter Fingers expire → Kill
Si l’œuf n’est pas récupéré quand il tombe : HF perdu → reset.
Hotfix du 25/08/2026 : durée du Greasy Hatchling portée à 35 s (au lieu de 20).
Sources : Wowhead — HFWarcraft Wiki — hotfix
